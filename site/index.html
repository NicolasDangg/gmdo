Get my data out

A command-line tool where a TinyFish agent signs in to your school’s Canvas and saves every grade, assignment and file you have there.

Three commands

Sign in once, export, open the files. TinyFish does the browsing; gmdo keeps the record straight.

Sign in once, yourself.

gmdo opens a TinyFish browser profile on your school’s sign-in page. You log in there, Google or Microsoft included. The profile keeps the cookies; gmdo keeps only the profile id.

gmdo setup

Export everything.

Every course’s Grades page goes to the TinyFish agent as one run, all in a single batch. gmdo follows each run to the end and compares the rows it read with the number Canvas reports.

gmdo export --terms "2025-2026,2026-2027"

Questions

Does gmdo ever see my password? No. gmdo setup opens a TinyFish browser on your school’s sign-in page and you sign in there yourself, Google or Microsoft included. The browser profile keeps the cookies. The tool stores a profile id and nothing else.

What does TinyFish do here? Four things. A browser profile holds your sign-in. The agent opens each course’s Grades page and reads every row, sent as one batch of runs. The runs endpoint tracks each run to the end and resumes after a crash. The same signed-in browser downloads your files.

Why have an agent read the page? It reads what you can see, the way you would. gmdo also reads the data Canvas loads behind that page, and uses it to check the agent: the count of assignments per course, and whether each score matches.

What does a run cost? TinyFish charges per agent step, $0.016 at the time of writing. A course takes six to twelve steps. Unchanged courses are never sent, so a rerun in a quiet week costs nothing. --dry-run prints the estimate first, and --budget stops anything above it.

What happens if I get signed out? gmdo notices before it exports anything and tells you to run gmdo setup again. It never saves a sign-in page as your data.

What if a run comes back short or fails? It is read once more. If it is still short, courses.csv marks the course incomplete and manifest.json lists the assignments that are missing.

What if Canvas hasn’t posted a grade? The cell stays empty and the row records Canvas’s own state, such as pending review. gmdo never fills in a number.

Is this allowed? It reads your own account, at a human pace, and the agent is told never to submit or change anything. Check your school’s rules before running it on a schedule.

Can I share my export? Run gmdo showcase. Course names become plain subjects, names of students and teachers become [student] and [teacher], comments become a count, and the copy is searched for every name before it is kept.

Does it work on other portals? It is built and tested on one school’s Canvas. Everything Canvas-specific lives in one adapter file, so another Canvas school should need little or no change.
